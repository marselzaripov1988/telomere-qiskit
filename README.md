# telomere-qiskit

Квантово-химическая модель фрагмента теломеры (`TTAGGG`)ₙ в `qiskit-nature`.

Берётся одно основание повтора (по умолчанию гуанин — основа G-квадруплексов
и главная мишень окислительного повреждения теломер) и считается в малом
активном пространстве вокруг HOMO/LUMO.

**Пайплайн:** SMILES → 3D (RDKit, MMFF) → HF/STO-3G (PySCF) → `ActiveSpaceTransformer`
→ `ParityMapper` → VQE(UCCSD) + точная диагонализация для проверки.

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python telomere_guanine.py                 # G, (4e,4o) -> 6 кубитов
.venv/bin/python telomere_guanine.py --base T        # A или T
.venv/bin/python telomere_guanine.py --ne 6 --no 6   # 10 кубитов
```

## Результат (G, STO-3G, 4e/4o, 6 кубитов)

| Метод | Энергия, Ha |
|---|---|
| Хартри–Фок | −532.44894 |
| VQE (UCCSD, 26 параметров) | −532.45789 |
| Точный (CASCI) | −532.45789 |

|VQE − exact| ≈ 1·10⁻⁶ Ha. Учебный масштаб: минимальный базис и малое активное
пространство — для отработки метода, не для сравнения с экспериментом.

## Стэкинг G–G (`stacking_gg.py`)

Два соседних гуанина G-цепочки: шаг d по нормали, twist 36° (B-ДНК).
Энергия взаимодействия с противовесной поправкой BSSE (ghost-атомы).
Квантовая часть: π-активное пространство, димер (4e,4o) = 6 кубитов, мономер (2e,2o) = 2 кубита.

```bash
.venv/bin/python stacking_gg.py                         # скан d = 3.0…5.0 Å, VQE на 3.4 Å (~15 мин)
.venv/bin/python stacking_gg.py --dists 3.4 --twist 0   # одна точка, без закрутки
```

ΔE, ккал/моль, STO-3G:

| d, Å | HF | MP2 | CAS (exact) | VQE |
|---|---|---|---|---|
| 3.0 | 14.96 | 11.08 | 15.06 | — |
| 3.2 | 7.99 | 4.88 | 7.95 | — |
| 3.4 | 4.70 | 2.20 | 4.62 | 4.63 |
| 3.7 | 2.74 | 0.92 | 2.67 | — |
| 4.0 | 2.06 | 0.70 | 2.00 | — |
| 5.0 | 1.29 | 0.71 | 1.26 | — |

Проверка на 3.4 Å с базисом 6-31G*: ΔE(HF) = +8.82, ΔE(MP2) = **−1.44** ккал/моль.

Выводы: VQE воспроизводит точный CAS (расхождение ~0.003 ккал/моль), но
π-CAS(4,4) даёт лишь ~0.1 ккал/моль корреляции — стэкинг держится на
дисперсии, размазанной по всем электронам. В STO-3G дисперсии почти нет,
и остаётся электростатическое отталкивание параллельных диполей G.
Притяжение появляется только с поляризационными функциями (MP2/6-31G*).

## G-тетрада с K⁺ (`tetrad_geometry.py`, `g_tetrad_k.py`)

Четыре гуанина, связанные по Хугстину (N1–H···O6′, N2–H···N7′), симметрия C4,
K⁺ над центром на h = 1.70 Å (K–O6 = 2.80 Å, как в квадруплексе между двумя тетрадами).
Геометрия: `g_tetrad_K.xyz` (N1···O6′ = 2.83 Å, N2···N7′ = 2.83 Å, O6···O6′ = 3.15 Å).

65 атомов / 253 АО — 4-индексные интегралы через `PySCFDriver` непрактичны, поэтому
гамильтониан активного пространства берётся из PySCF (CASCI `h1eff`/`h2eff`) и передаётся
в qiskit-nature через `ElectronicEnergy.from_raw_integrals`; точная диагонализация
сверяется с CASCI PySCF.

```bash
.venv/bin/python tetrad_geometry.py   # геометрия -> g_tetrad_K.xyz
.venv/bin/python g_tetrad_k.py        # энергии, ~6 мин
```

STO-3G, CAS(4e,4o) = 6 кубитов, ккал/моль, с поправкой BSSE:

| Величина | HF | MP2 | CAS (exact) | VQE |
|---|---|---|---|---|
| Связывание K⁺ тетрадой | −62.13 | −55.51 | −62.11 | −62.11 |
| Образование тетрады из 4 G | −34.78 | −36.93 | — | — |

Выводы: связывание K⁺ — почти чистая электростатика (ион–диполь с четырьмя O6),
её ловит уже HF. LUMO комплекса на 92 % состоит из 4s K⁺, т.е. активное пространство
описывает перенос заряда тетрада→K⁺, но его корреляционный вклад ~0.02 ккал/моль.
VQE совпадает с точным CAS до ~10⁻⁴ ккал/моль. Образование тетрады в STO-3G
(~−4.5 ккал/моль на H-связь) — оценка снизу: минимальный базис занижает H-связи.

### 6-31G*, активное пространство O6 → K⁺ (10 кубитов)

```bash
.venv/bin/python g_tetrad_k.py --basis 6-31g* --active o6k --ne 6 --no 6   # ~2.5 ч, из них VQE ~2 ч
```

Активное пространство CAS(6e,6o): 3 занятых уровня неподелённых пар O6 (ранжированы по обмену
Σₐ(ia|ia) с K-орбиталями) + 4s/4p K⁺ (у T(TK) — те же функции на ghost-центре K); уровни C4
берутся целиком. UCCSD — 117 параметров, VQE ~1 ч на систему. Промежуточные результаты
кэшируются в `chk/*.json`.

| Величина, ккал/моль | HF | MP2 | CAS (exact) | VQE |
|---|---|---|---|---|
| Связывание K⁺ тетрадой | −75.81 | −70.95 | −75.81 | −75.81 |
| Образование тетрады из 4 G | −45.08 | −56.84 | — | — |

Корреляция активного пространства: −0.8·10⁻⁶ Ha (комплекс), −0.4·10⁻⁶ Ha (тетрада);
для сравнения MP2 — −6.47 Ha. |VQE − CAS| ≤ 2·10⁻⁶ ккал/моль.

Выводы:
- Поляризационные функции заметно усиливают оба эффекта по сравнению с STO-3G:
  K⁺ −62 → −76, тетрада −35 → −57 ккал/моль (MP2; ~−7 на H-связь).
- Связывание K⁺ — электростатика + поляризация, описывается уже HF. Корреляция (MP2)
  его ослабляет на ~5 ккал/моль.
- Статической корреляции O6 → K⁺ нет: пары O6 и диффузные 4s/4p K почти не перекрываются,
  CAS ≈ HF. Квантовый решатель здесь честно воспроизводит ответ, но не нужен —
  вся значимая корреляция динамическая, размазана по сотням орбиталей, и это область MP2/CCSD.

## Классический эталон для G⁺ и GG⁺

- `ref_g_cation.py`: вертикальный (VIE) и адиабатический (AIE) потенциалы ионизации гуанина.
  Геометрии B3LYP/cc-pVDZ (geomeTRIC). Методы: ΔHF/ΔMP2/ΔCCSD/ΔCCSD(T) (UHF-референс для катиона,
  frozen core), EOM-IP-CCSD и поправка на базис δaug = ΔMP2/aug-cc-pVDZ − ΔMP2/cc-pVDZ.
- `ref_gg_cation.py`: локализация дырки в GG⁺ тракта GGG теломерного G-квадруплекса
  (PDB 1KF1, остатки 2–3, `data/1KF1.pdb`, геометрия в `results/gg_1KF1.xyz`).
  Методы: UHF/UB3LYP/UCAM-B3LYP в газе, в поле K⁺ кристалла (точечные заряды) и в PCM (вода),
  а также SA-CASSCF(7,6)/NEVPT2 с FCD-моделью (V, Δ).

Результаты кэшируются в `results/g_cation.json` и `results/gg_cation.json`.

### G⁺: потенциалы ионизации, эВ

| Метод | VIE | AIE |
|---|---|---|
| ΔHF/cc-pVDZ | 6.70 | 6.30 |
| ΔMP2/cc-pVDZ | 8.47 | 7.99 |
| ΔCCSD/cc-pVDZ | 7.63 | 7.24 |
| ΔCCSD(T)/cc-pVDZ | 7.64 | 7.27 |
| ΔMP2/aug-cc-pVDZ | 8.87 | 8.39 |
| **ΔCCSD(T)/cc-pVDZ + δaug** | **8.04** | **7.68** |
| EOM-IP-CCSD/cc-pVDZ (+ δaug) | 7.68 (8.08) | — |
| Эксперимент | 8.24 | 7.77 |

Пояснения к таблице:

- ΔCCSD(T) с поправкой на базис отстаёт от эксперимента на 0.2 эВ (VIE) и 0.1 эВ (AIE).
  Оставшаяся разница ожидаема для базиса двойной ζ.
- UHF-референс катиона сильно спин-загрязнён: ⟨S²⟩ = 1.02 при идеале 0.75.
  Поэтому ΔMP2 завышает IP на 0.4–0.8 эВ.
- T1-диагностика: G 0.023, G⁺ 0.043 (выше порога 0.02 для открытых оболочек).
  Это признак мультиреферентного характера G⁺, то есть мотивация для CAS/квантовых методов.
- EOM-IP-CCSD (без спин-загрязнения) даёт D0 = 7.68, D1 = 9.35, D2 = 9.64 эВ.
  Щель D0–D1 составляет 1.67 эВ.
- π-CASSCF(14e,11o)/NEVPT2 для G⁺: в работе (CASSCF нейтрали не сошёлся за 100 итераций).

### GG⁺ (1KF1, 5′-G2/3′-G3): доля дырки на 5′-G / 3′-G

| Метод | газ | поле K⁺ | PCM |
|---|---|---|---|
| UHF | 0.98 / 0.02 | 0.98 / 0.02 | 0.48 / 0.52 |
| UB3LYP | 0.70 / 0.30 | 0.69 / 0.31 | 0.55 / 0.45 |
| UCAM-B3LYP | 0.96 / 0.04 | 0.94 / 0.06 | 0.45 / 0.55 |

Пояснения к таблице:

- В газе и в поле K⁺ гибридный UB3LYP делокализует дырку (самодействие), а UHF и CAM-B3LYP
  локализуют её на 5′-G. В PCM дырка делокализована во всех методах.
- Предсказание зависит от метода. Это и есть задача, где нужен многоконфигурационный эталон.
- Поле K⁺ задаётся только точечными зарядами трёх ионов, без противоионов (фосфатов).
  Поэтому абсолютный IP в поле K⁺ завышен (≈14 эВ) и физически не интерпретируется;
  интерпретируется только распределение дырки.

### GG⁺: SA4-CASSCF(7,6)/cc-pVDZ, пара состояний с переносом дырки (FCD)

Активное пространство: 4 занятые π-орбитали (HOMO и HOMO−1 каждого G) и 2 виртуальные π-орбитали.
Усреднение ведётся по 4 состояниям с равными весами. Для FCD берутся нижнее состояние с дыркой
на 5′-G и нижнее с дыркой на 3′-G.

| | газ | поле K⁺ (точечные заряды) |
|---|---|---|
| дырка в D0 (5′ / 3′) | 0.20 / 0.80 | 0.99 / 0.01 |
| дырка в D1 (5′ / 3′) | 0.82 / 0.18 | 0.02 / 0.98 |
| щель D0–D1, CASSCF | 0.143 эВ | 2.13 эВ |
| V (FCD, CASSCF) | **71 мэВ** | (1009 мэВ, см. ниже) |
| Δ (FCD, CASSCF) | **19 мэВ** | 666 мэВ |

Пояснения к таблице:

- Газовая фаза: два почти вырожденных состояния с переносом дырки.
  Двухуровневая проверка сходится: √(Δ² + 4V²) = 143 мэВ, то есть точно щель CASSCF.
  Величина V ≈ 70 мэВ типична для стэкинга GG в B-форме и в квадруплексах (50–100 мэВ).
- Расхождение с UHF/UCAM-B3LYP: SA-CASSCF без динамической корреляции помещает дырку
  преимущественно на 3′-G, а UHF/UCAM-B3LYP — на 5′-G.
- Поле K⁺: три голых заряда +1 без противоионов (фосфатов) сдвигают энергию дырки на 5′-G
  примерно на 2 эВ. FCD вне двухуровневого режима, и V ≈ 1 эВ — артефакт модели среды, а не
  физическая величина. Нужна электронейтральная среда: K⁺ + фосфаты 1KF1 или QM/MM с противоионами.
- SC-NEVPT2 по отдельным корням для газовой фазы меняет порядок состояний: поправки двух корней
  различаются на 0.77 эВ при щели CASSCF 0.14 эВ. Для близких состояний нужен
  квазивырожденный QD-NEVPT2, которого нет в PySCF 2.14 (есть в pyscf-forge).
  Поэтому V и Δ на уровне NEVPT2 здесь не приводятся.

Методы расходятся в положении дырки на 5′ или 3′, и эффект динамической корреляции на почти
вырожденную пару велик. Этот раздел мотивирует более точный многоконфигурационный расчёт:
большее активное пространство, QD-NEVPT2 и квантовые методы (SQD/VQE).
